# Maid Odyssey

为 [GregTech Odyssey](https://github.com/GregTech-Odyssey/GregTech-Odyssey) 与 [车万女仆](https://www.curseforge.com/minecraft/mc-mods/touhou-little-maid) 提供兼容的 Minecraft 1.20.1 Forge 模组。

女仆会替你打理格雷科技工厂里两件最烦人的杂活；干不下去时，她会在公屏说明原因，而不是默默站着发呆。

## 功能

| 工作模式 | 做什么 |
| --- | --- |
| **清理消声仓** | 把附近消声仓里堆积的灰烬收进背包 |
| **维护维护仓** | 用背包里的工具修复损坏的维护仓 |
| **工厂维护员** | 上面两件事一起做 |

- 消声仓在多方块顶上时，女仆会站在地面够得到的地方清理，不必爬到屋顶。
- 维护仓的六种故障分别对应扳手、螺丝刀、橡胶锤、锤子、剪线钳、撬棍。电动工具也能用。缺工具时可以用格雷胶带临时糊住。
- 全自动 / 净化维护仓不会坏，女仆会自动跳过。
- 背包满了、缺工具、走不到机器旁边时，会在聊天框向全服播报，并带上女仆名字和坐标。

## 使用

1. 给女仆一个背包，打开界面选好上面的工作模式。
2. **打开家模式**，把家点设在工厂附近，让工作范围盖住要照看的机器。
3. 清理消声仓需要背包空位；维护维护仓需要把对应工具放进背包。

没开家模式时，车万女仆只会在主人身边活动，起不到看厂的作用。

## 前置

- Minecraft 1.20.1、Forge 47
- 车万女仆 1.4.0 或更高
- GregTech Odyssey 整合包（或其中的 GregTech Modern）

## 配置

进游戏后会生成 `config/maid_odyssey-common.toml`，可以调整：

- 聊天是全服可见还是只发给主人，以及是否播报成功的工作
- 搜索范围、站在多远内可以干活
- 灰烬是收进背包还是直接销毁
- 缺工具时是否使用胶带、工具耐久下限
